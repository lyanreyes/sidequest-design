# SideQuest: design and promo

Design work for **SideQuest: Find Gigs, Earn Fast**, a location-based gig app by Group 5, BSCS 3A, FAITH Colleges. The app code lives in [lyanreyes/sidequest](https://github.com/lyanreyes/sidequest).

| Folder | What it is |
|---|---|
| `figma-plugin/` | Figma development plugin that builds the full design system and 17 linked prototype screens (`node build.js`) |
| `html-prototype/` | Clickable HTML/CSS version of all 17 screens. [Try it live](https://lyanreyes.github.io/demos/sidequest/index.html) |
| `promo/` | Promo video with voiceover (`SideQuest-Promo.mp4`), voiceover script, landing page, and the recorder used to capture it |

Download the Android app: [SideQuest.apk](https://github.com/lyanreyes/sidequest/releases/latest/download/SideQuest.apk)
